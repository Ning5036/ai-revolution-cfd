## 改內容

只改 `src/page.html`，然後：

```bash
python3 build.py   # 產生 index.html
git add -A && git commit -m "..." && git push
```

`src/page.html` 是不含 `<html>／<head>／<body>` 的片段（同時給 Claude Artifact 用）；
`build.py` 幫它套上完整文件外殼、`noindex` 與 favicon。
